# Backend structure

Install the backend packages and create the Express server in the next setup step.

- `src/config`: database and application configuration.
- `src/controllers`: request-handling logic.
- `src/middlewares`: shared Express middleware.
- `src/models`: Mongoose schemas and models.
- `src/routes`: API endpoint definitions.
- `src/utils`: small reusable helper functions.
- `uploads`: local image uploads during development.
- `tests`: backend tests added as API features are built.
